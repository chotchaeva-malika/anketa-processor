# Обработчик анкет

Программа читает файл с анкетами, проверяет корректность ФИО, почты и телефона, выводит сводную таблицу со статистикой и сохраняет валидные и ошибочные записи в отдельные файлы.

## Запуск
```bash
python main.py
```

## Формат входного файла
Файл `anketa.txt` должен находиться в корне проекта в кодировке UTF-8. Формат каждой строки (разделитель — точка с запятой):
`ФИО ; почта ; телефон ; группа`
