# Обработчик анкет

Программа читает файл с анкетами студентов и преподавателей, проверяет корректность данных, выводит сводную таблицу со статистикой и сохраняет валидные и ошибочные записи в отдельные файлы.

## Структура проекта
* `people.py` — классы `Person`, `Student`, `Teacher`, исключение `AnketaError` и разбор строки.
* `registry.py` — класс `Registry` для загрузки файла, хранения анкет, подсчёта статистики и сохранения результатов.
* `main.py` — запуск программы и вывод отчёта в консоль.

## Запуск
```bash
python main.py
```

## Формат входного файла
Файл `anketa.txt` должен находиться в корне проекта в кодировке UTF-8. Формат каждой строки (разделитель — точка с запятой):
`тип ; ФИО ; почта ; телефон ; группа или кафедра`
* `s` — студент (в конце указывается группа)
* `t` — преподаватель (в конце указывается кафедра)
